# Jira behaviours

The Jira Cloud source. It is read only, so it has no write command. Descriptions arrive as Atlassian Document Format and
are rendered as escaped Markdown.

## Files

- [jira-operations.feature](jira-operations.feature): the account, project, issue, and comment reads, the JQL check, the
  rendering of hostile text, and the rule that the token and e-mail address go only to the Jira endpoint.
