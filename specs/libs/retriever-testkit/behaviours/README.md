# Testkit Behaviours

Feature files for the `retriever-testkit` library. Each file covers one area of its exported API or its test commands.

## Files

- [in-memory-file-tree.feature](in-memory-file-tree.feature): the in-memory file tree that stands in for a disk.
- [jira-stub.feature](jira-stub.feature): the fake Jira Cloud REST server.
- [jira-stub-command.feature](jira-stub-command.feature): the test command that serves the Jira stub as a process.
- [kiwi-stub.feature](kiwi-stub.feature): the fake Kiwi TCMS JSON-RPC server.
- [kiwi-stub-command.feature](kiwi-stub-command.feature): the test command that serves the Kiwi stub as a process.
- [outline-stub.feature](outline-stub.feature): the fake Outline API with replies, faults, and a request log.
- [outline-stub-command.feature](outline-stub-command.feature): the test command that serves the Outline stub as a process.
- [source-contract-suite.feature](source-contract-suite.feature): the shared source contract suite and its reference fake.
- [synthetic-replies.feature](synthetic-replies.feature): the embedded synthetic Outline replies.
