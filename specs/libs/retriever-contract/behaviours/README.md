# Contract Behaviours

Feature files for the `retriever-contract` library. Each file covers one area of its exported API.

## Files

- [arguments-and-binding.feature](arguments-and-binding.feature): binding the arguments of one call to one operation row.
- [contract-version.feature](contract-version.feature): the version constant of the contract.
- [endpoints.feature](endpoints.feature): source endpoints, which are HTTPS host names only.
- [identifiers.feature](identifiers.feature): collection, document, source, tag, UUID, and share IDs.
- [identity-and-credentials.feature](identity-and-credentials.feature): identity and credential variable names, and
  redacted key and address values.
- [operation-catalog.feature](operation-catalog.feature): operation rows, kinds, closed lists, effects, and resources.
- [plugin-pins.feature](plugin-pins.feature): plugin references and their SHA-256 pins.
- [public-errors.feature](public-errors.feature): which error texts a presenter may show.
- [records-and-pages.feature](records-and-pages.feature): bound arguments, result records, and pages.
- [source-kinds.feature](source-kinds.feature): source kinds, kind sets, and kind-specific error texts.
- [sources-and-catalog.feature](sources-and-catalog.feature): catalog construction, lookup, filters, and selection.
- [text-values.feature](text-values.feature): the value checks for text, numbers, times, and lists.
