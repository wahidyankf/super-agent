# Applications

`apps/` will hold the runnable parts of super-agent. Nothing is here yet, and no Nx project is declared.

The first application is `apps/retriever-cli`, the command-line tool. It arrives in the next pull request. Its
binary is named `retriever`, and its Go module path is `github.com/wahidyankf/super-agent/apps/retriever-cli`.
Each application gets its own README, with its prerequisites, commands, and tests.
