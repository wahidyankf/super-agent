# Applications

`apps/` holds the runnable parts of super-agent. It holds one application so far:

- [retriever-cli/](retriever-cli/) is the command-line tool, with its own [README](retriever-cli/README.md). Its binary is named `retriever`, and its Go module path
  is `github.com/wahidyankf/super-agent/apps/retriever-cli`.

Each application gets its own README, with its prerequisites, commands, and tests.
