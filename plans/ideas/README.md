# Ideas

This folder holds two-pagers: short idea briefs that are richer than a one-line todo but are not yet full plans.
Each idea is one `<slug>.md` file, in kebab-case. An idea moves to [`backlog/`](../backlog/) as a full plan when its
open questions are settled.
