# Repository Governance

This folder holds the rules for super-agent. super-agent is alpha. Its rules say how the repository is written, secured,
built, tested, released, and kept compatible with the people and harnesses that use it.

The root [AGENTS.md](../AGENTS.md) gives the contributor's first instructions. Read this folder for the full rules.

## Directory Map

- [Glossary](./glossary.md): the meaning of each project term, such as super agent, connector, source, and catalog.
- [Conventions](./conventions/): the rules for files, writing, security, structure, and the command-line
  interface.
- [Development](./development/): the rules for specifying, building, testing, and releasing a change.
- [Principles](./principles/): the reasons behind the rules, such as minimal sufficiency and fail closed.
- [Vision](./vision/): what super-agent is for, and what it deliberately does not do.
- [Workflows](./workflows/): the ordered steps for pull requests, documentation, rules, leak reviews, and
  releases.
