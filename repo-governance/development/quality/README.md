# Quality

Quality rules say how the code and its tests must look and what a check must prove.

## Directory Map

- [Checks](./checks/README.md): the test and gate contract, rules C1 to C24, and its seven modules.
- [Testing](./testing/README.md): the rules for coverage and what a coverage number measures.
- [Current Behaviour Over Past Proof](./current-behaviour-over-past-proof.md): recording a current observation when
  past proof can no longer be produced.
- [Nx Targets](./nx-targets.md): the target names that projects expose and what each must do.
- [Stacks](./stacks/README.md): the standards for the Go code, the shell scripts, and how the repository applies stack
  packs.
