# Conventions

Conventions state how things in this repository must look and behave. Each one says what it covers and who checks it.

## Directory Map

- [Command-Line Interface](./command-line-interface.md): the exit statuses, streams, output, flags, and terminal rules
  for every command-line entry point. Its modules sit in [command-line-interface/](./command-line-interface/README.md).
- [Writing](./writing/README.md): content quality, word limits, diagrams, line length, file naming, the Diataxis docs
  layout, and web research delegation.
- [Security](./security/README.md): the rules that keep secrets, machine details, and private data out of tracked and
  published files.
- [Structure](./structure/README.md): the layout of agent bindings, specs, plans, related repositories, and stack packs.
