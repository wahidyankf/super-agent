# Workflows

Workflows are ordered steps with a stated end. Each one names the checks that must pass before the next step starts.

## Directory Map

- [Maintenance](./maintenance/README.md): delivering a change through a pull request, cleaning up afterwards, and
  cutting a release.
- [Quality](./quality/README.md): carrying rule and documentation changes to every place they affect, and reviewing pull
  requests for leaks.
