# Quality Workflows

## Directory Map

- [Rules Propagation](./rules-propagation.md): how a rule is stated once, enforced, and carried to every binding that
  depends on it.
- [Docs Propagation](./docs-propagation.md): how documentation changes in the same pull request as the behaviour it
  describes.
- [Pull Request Leak Review](./pr-leak-review.md): how every pull request is read for leaks before it merges.
