# Serena Project Configuration

Git tracks only this README under `.serena/`. `.gitignore` ignores everything else in the folder, so caches,
memories, logs, local overrides, and other runtime files stay on your machine.

This checkout has no tracked Serena project configuration yet. If one is added, it must follow the [public data
policy](../docs/explanation/public-data-policy.md): no paths, host names, addresses, or other machine-specific
values.
